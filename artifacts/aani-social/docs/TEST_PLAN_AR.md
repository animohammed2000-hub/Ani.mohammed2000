# خطة اختبار مساعد آني

نفّذ اختبارات الاتصال في مشروع Supabase مرحلي، لا على بيانات الإنتاج. كل سجل
يجب أن يحتوي `requestId` ومرحلة و`elapsedMs`، دون نص المحادثة أو رموز الدخول.
لم تُنفذ اختبارات اتصال حي في هذه النسخة لعدم توفر إعدادات المالك.

| الاختبار | الإجراء | النتيجة المتوقعة | السجل/تفسير الفشل |
|---|---|---|---|
| تسجيل الدخول ورسالة صحيحة | سجّل الدخول وأرسل سؤالًا قصيرًا | يظهر رد غير فارغ ويختفي التحميل | المراحل تصل إلى `request_succeeded`؛ توقف `auth_check` يعني مشكلة جلسة |
| سياق المحادثة | أرسل سؤال متابعة يعتمد على الرد السابق | يستخدم Gemini الرسائل السابقة ضمن الحد | `messageCount` أكبر من 1؛ لا تسجل النصوص |
| رسالة فارغة | أرسل فراغًا من الواجهة، ثم اختبر طلبًا مباشرًا فارغًا في بيئة مرحلية | الواجهة لا ترسل؛ الدالة ترفض المباشر بـ 400 | `EMPTY_MESSAGE` أو منع محلي صحيح |
| رسالة طويلة | أدخل أكثر من 4,000 حرف، ثم اختبر الدالة مباشرة | يظهر رفض مفهوم؛ لا يبقى التحميل | `MESSAGE_TOO_LONG` أو 413 |
| تجاوز حجم المحادثة | أرسل سياقًا يتجاوز 16,000 حرف | ترفضه الدالة قبل Gemini | `CONVERSATION_TOO_LONG` ومرحلة `validation_rejected` |
| انتهاء المهلة | اختبر اتصالًا بطيئًا في بيئة مرحلية | الواجهة تنهي الانتظار خلال 30 ثانية وتسمح بالإعادة | `GEMINI_TIMEOUT` و`gemini_timeout` |
| انقطاع الشبكة | افصل الشبكة أثناء الطلب | تظهر رسالة اتصال ويختفي التحميل | قد لا يصل الطلب للدالة؛ إن وصل، راجع `requestId` |
| جلسة منتهية | أرسل بطلب جلسة منتهية | HTTP 401 ورسالة تسجيل دخول | `auth_check_finished` مع `invalid` |
| مصدر CORS غير مسموح | استخدم أصلًا غير موجود في `ALLOWED_ORIGINS` | يمنع المتصفح الطلب؛ لا يتجاوز ذلك المصادقة | `cors_rejected` |
| مفتاح Gemini مفقود | في مشروع مرحلي، أزل المفتاح مؤقتًا | رسالة إعداد، ولا ينتظر المستخدم طويلًا | `gemini_not_configured` |
| مفتاح غير صالح | استخدم مفتاحًا اختباريًا غير صالح في بيئة مرحلية | خطأ وصول واضح بلا تفاصيل سرية | `gemini_upstream_error` مع 401/403 |
| تجاوز الحصة | استعمل حسابًا مرحليًا وصل للحد | رسالة حد استخدام قابلة لإعادة المحاولة | 429 upstream ثم `GEMINI_RATE_LIMITED` |
| نموذج غير متاح | ضع اسمًا غير صالح في `GEMINI_MODEL` في بيئة مرحلية | رسالة إعداد النموذج | upstream 404 ثم `GEMINI_MODEL_NOT_FOUND` |
| JSON غير صالح من Gemini | اختبر parser في اختبار محلي/مُحاكى، لا بتغيير خدمة الإنتاج | خطأ آمن والتحميل ينتهي | `gemini_json_parse_failed` |
| رد فارغ أو محجوب | استخدم استجابة مرحلية مناسبة للاختبار | خطأ مفهوم، ولا يعرض النص الفارغ كنجاح | `gemini_empty_response` أو `gemini_prompt_blocked` |
| ضغط إرسال متكرر | اضغط الإرسال عدة مرات بسرعة | طلب واحد فقط | طلب واحد يحمل requestId واحدًا |
| إعادة المحاولة | افشل طلبًا ثم أعده | لا تتكرر رسالة المستخدم في السياق | يظهر requestId جديد، ولا تتكرر الرسالة |
| إغلاق النافذة | أغلق المحادثة أثناء الطلب ثم افتحها | يتوقف انتظار الواجهة؛ لا يعد الإلغاء ضمانًا لإيقاف الخادم | قد يسجل الخادم نجاحًا لاحقًا؛ لا تُعرض نتيجة قديمة |
| الدالة غير منشورة | وجّه بيئة اختبار إلى اسم دالة غير متاح | خطأ واضح وينتهي التحميل | لا يوجد سجل جديد للدالة؛ افحص HTTP واسم النشر |
| أدوات المؤسس | جرّب الوصول إلى إدارة أو تعديل ملفات | لا توجد واجهات أو أدوات إدارية في هذه النسخة | الاختبار الأمني الكامل مؤجل إلى تنفيذ الأدوات المقيدة |
| سلامة التطبيق | افتح الدخول، الخلاصة، البحث، الملف، الرسائل، القصص والريلز | لا تتأثر الوظائف الحالية | راجع أخطاء المتصفح وطلبات Supabase |

## النتيجة المنفذة فعليًا

- فحص TypeScript لواجهة React: نجح.
- بناء Vite: نجح، مع تحذير غير مانع في sourcemap لملف tooltip وتحذير أن
  حزمة JavaScript تتجاوز 500 كيلوبايت.
- فحص TypeScript لدوال Supabase: نجح باستخدام تعريف Deno مؤقت للفحص فقط؛
  Deno CLI غير مثبت في مساحة العمل.
- اختبار منطق الدالة بمحاكاة `fetch` في Node: نجحت حالات 401 لغياب/رفض
  الجلسة، 200 لرد Gemini محاكى مع الحفاظ على `requestId`، 403 لمصدر غير
  مسموح، و413 لجسم يتجاوز حد 64 كيلوبايت. هذا لا يثبت عمل نشر Supabase أو
  الاتصال الحقيقي بخدمات المالك.
- سير عمل المعاينة بدأ دون أخطاء تشغيل. لقطة الشاشة تعرض شاشة الدخول وتنبيه
  غياب إعدادات Supabase.
- لم يُسجّل دخول ولم يُستدعَ Gemini أو مشروع Supabase الحقيقي. لذلك تبقى
  اختبارات الصفوف أعلاه التي تحتاج إعدادات المالك غير منفذة.
