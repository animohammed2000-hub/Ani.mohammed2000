# عقد مساعد آني

هذا العقد هو المصدر المشترك بين واجهة المحادثة ودوال Supabase. لا ترسل
`GEMINI_API_KEY` أو أي مفتاح إداري من المتصفح.

## المسار الأساسي

`POST {VITE_SUPABASE_URL}/functions/v1/gemini-chat`

الرؤوس:

- `apikey`: مفتاح Supabase العام المخصص للمتصفح.
- `Authorization: Bearer <user access token>`: جلسة المستخدم الحالية.
- `Content-Type: application/json`
- `x-request-id`: معرّف UUID ينشئه المتصفح لكل محاولة.

الجسم:

```json
{
  "messages": [
    { "role": "user", "content": "رسالة المستخدم" },
    { "role": "assistant", "content": "رد سابق" },
    { "role": "user", "content": "الرسالة الحالية" }
  ]
}
```

القواعد:

- يجب أن تكون الرسالة الأخيرة من `user`.
- الحد الأقصى 20 رسالة، و4,000 حرف لكل رسالة، و16,000 حرف للمحادثة
  المرسلة.
- لا تُرسل رسائل واجهة الخطأ ضمن السياق.
- يرفض الخادم الطلب غير المسجل الدخول حتى لو استُدعيت الدالة مباشرة.

النجاح (`200`):

```json
{
  "text": "رد Gemini",
  "model": "gemini-3.8-flash",
  "finishReason": "STOP",
  "requestId": "uuid"
}
```

الخطأ:

```json
{
  "error": {
    "code": "AUTH_REQUIRED",
    "message": "سجّل الدخول ثم أعد المحاولة."
  },
  "requestId": "uuid"
}
```

أكواد الخطأ المتوقعة تشمل `AUTH_REQUIRED` و`ORIGIN_NOT_ALLOWED` و
`MESSAGE_TOO_LONG` و`GEMINI_TIMEOUT` و`GEMINI_RATE_LIMITED` و
`GEMINI_MODEL_NOT_FOUND` و`EMPTY_MODEL_RESPONSE`.

المسار القديم `/functions/v1/ai-assistant` محمي أيضًا، لكنه يحتفظ برد النجاح
القديم `{ "reply": "..." }` لتقليل كسر العملاء السابقين. كلا المسارين يقبل
شكل الطلب القديم `{ message, history }`. الواجهة النشطة تستعمل
`gemini-chat` فقط.

## المهلات والسجلات

- الواجهة: 30 ثانية كحد أقصى لكل طلب.
- التحقق من جلسة Supabase: 8 ثوانٍ.
- اتصال Gemini وقراءة رده: 20 ثانية.
- يحمل كل طلب `requestId` واحدًا في سجلات الدالة والرد.
- السجلات لا تحتوي نص المحادثة أو رموز الجلسة أو مفاتيح الخدمات.
- إلغاء `AbortController` يوقف انتظار الواجهة/اتصالها؛ لا يضمن إيقاف عمل
  الدالة أو الطلب المرسل إلى Gemini بعد وصوله إلى الخادم.

## حدود الصلاحيات الحالية

هذه النسخة تنفذ محادثة Gemini فقط. لا تملك الدالة أدوات لقراءة ملفات Replit أو
تعديلها أو تشغيل أوامر أو إدارة بيانات الأعضاء. لا يجوز للنموذج الادعاء بأنه
نفّذ شيئًا خارج المحادثة. أي أداة مستقبلية تحتاج إلى خدمة خلفية مستقلة،
تحقق مؤسس على الخادم، قائمة سماح ضيقة، سجل تدقيق، وموافقة صريحة قبل التغيير.
